プライバシーポリシー

アプリ Arrímalo（com.jrsoft.etiquetasnfc）· 最終更新日：2026年11月13日

ひとことで言うと：このアプリにはユーザーアカウントもサーバーもありません。タグから読み取った内容やタグに書き込んだ内容、テンプレート、履歴、パスワードは、スマートフォンの外に出ません（ご自身で新しいスマートフォンに移す場合を除きます）。データを送信するのは広告だけで、それを行うのは Google のライブラリです。

データ管理者

データ管理者は、このアプリの開発者である JR Soft（Javier Román Sáez の屋号）です。お問い合わせは demual@gmail.com までご連絡ください。

このアプリが行わないこと

  • 登録、アカウント、ユーザー名、独自のサーバーはありません。アプリはすべてスマートフォンの中で動作します。
  • 独自の分析ツールやクラッシュレポートツールは一切ありません。Google アナリティクスも Crashlytics も、その他の類似のツールも含まれていません。第三者に独自にデータを送信するライブラリは広告用のものだけで、その内容は下記のとおりです。このアプリには Firebase のリモート設定ライブラリ（Remote Config）が含まれています。新しいバージョンを公開せずに広告を調整するためのものですが、無効にしてあり、起動することもどのサーバーに接続することもありません。将来これを有効にする場合は、その前にこのポリシーを更新します。
  • 銀行カード、交通系カード、入館カードの読み取りやコピーはせず、カードのエミュレーションもしません。対象は標準の NFC タグだけです。こうしたカードを近づけると、アプリは標準のタグではないことをお知らせし、そのカードについては識別子も含めて何も保存しません。
  • スマートフォンの位置情報、カメラ、連絡先は使用しません。タスクのライトは、カメラを起動することもカメラの権限を求めることもなく点灯します。読み取った連絡先は、ご自身で連絡先アプリから追加した場合にのみ保存されます。
  • JR Soft がお客様のデータを保存することはなく（お送りいただいたメールを除きます）、データを含むリストやデータベースを誰かに渡すこともありません。広告の表示と効果測定のため、Google の広告 SDK（AdMob）が独自にデバイスの識別子やその他の技術データを収集し、Google に送信します（このポリシーで説明しているとおりです）。米国の一部のプライバシー法では、第三者の SDK にパーソナライズド広告のためにこうしたデータを収集させることを、個人データの「販売」または「共有」とみなしています。米国にお住まいの場合は、これを拒否できます（「米国にお住まいの方」を参照）。

スマートフォンの中だけに残るデータ

以下の情報はアプリ専用の保存領域に保存され、アプリの外に出ることはありません。アプリをアンインストールしたとき、または Android の設定からアプリのデータを消去したときに、すべて消去されます。履歴は、アプリ内の「履歴を消去」で消すこともできます。

  • 履歴：読み取ったものと書き込んだものの記録です。日時、読み取りか書き込みか、チップとそのメーカー、タグの識別子（UID）、タグの状態、容量、中身が含まれます。読み取った Wi-Fi ネットワークのパスワードは保存されません。保存されるのはネットワーク名とセキュリティの種類だけです。ご自身で書き込んだ Wi-Fi ネットワークについては、パスワードも保存されます。
  • テンプレート：もう一度書き込むために保存した内容です。
  • タグのパスワード：アプリからタグにパスワードを設定した場合、忘れたり毎回入力したりしなくて済むよう保存されます。パスワードは、スマートフォンの外に出ない Android の鍵保管庫（Android Keystore）の鍵で暗号化され、どのバックアップにも新しいスマートフォンへの転送にも含まれないフォルダに保存されます。
  • 設定：テーマと言語。
  • アプリの評価をお願いするのによいタイミングを選ぶためのカウンター（アプリを開いた回数と、前回お願いした日時）。
  • 「おやすみモード」のタスクを使う場合、Android は自身の設定に、このアプリの名前が付いた「おやすみモード」のルールを保存します。このルールは Android が管理しており、このアプリの「おやすみモード」へのアクセス権は、システムの設定で取り消せます。
  • SIM カードの国（SIM カードがない場合はシステムの地域）：「JR Soft のその他のアプリ」の画面が、お住まいの国で利用できるアプリだけを表示するために、その場で確認します。保存も送信もされません。この画面と「アプリを評価」「アプリを共有」にある Google Play へのリンクには、このアプリからのリンクであることだけを示すパラメータが付いており、ご自身のデータは含まれません。

タグに書き込んだ内容は、アプリではなくタグに残ります。タグにスマートフォンを近づければ誰でも読み取れます。パスワードがあっても同じです（パスワードは変更を防ぐだけです）。タグを見つけた人に読まれたくない内容は、タグに書き込まないでください。

バックアップ、機種変更、引き継がれないもの

このアプリのデータについては、Android のクラウドバックアップ（Google アカウントのバックアップ）を無効にしています。データは一切アップロードされません。Android は再インストールのために、インストールしていたアプリの一覧をアカウントに保存しますが、この一覧は Google が管理しており、アプリのデータは含まれません。

新しいスマートフォンの設定時に、古いスマートフォンからデータを直接コピーした場合（ケーブルの有無を問わず）、履歴、テンプレート、設定が新しいスマートフォンに移ることがあります。この転送はご自身が依頼し、Android が自身のツールまたはスマートフォンのメーカーのツールを使い、それぞれの条件に従って行います。Android のドキュメントによると、データはサーバーを経由せずにスマートフォン間で直接転送されます。私たちのサーバーを経由することは一切なく、JR Soft は何も受け取りません。転送が行われるかどうかは Android のバージョンとメーカーによって異なるため、保証することはできません。

古いスマートフォンでしか役に立たないものは引き継がれません。保存したタグのパスワード（その暗号鍵はスマートフォンの外に出せません）、広告に関するご自身の選択と広告の内部状態、Android の「おやすみモード」のルールです。新しいスマートフォンでは、必要なものをアプリがあらためて確認します。

スマートフォンの外に送信されるデータ

広告：Google AdMob

このアプリは、Google の広告 SDK（AdMob）が配信する控えめな広告を表示します。「マイタグ」画面（履歴とテンプレート）の下部に表示されるバナー広告と、履歴の項目の間に「広告」というラベル付きで表示されるネイティブ広告です。全画面広告はなく、タグの読み取り中や書き込み中、タスク、設定にも広告は表示されません。そのため、Android の広告 ID にアクセスするための権限 com.google.android.gms.permission.AD_ID を宣言しています。広告 ID は、Android の設定 → Google → 広告でリセットまたは削除できます。

広告 ID のほかに、AdMob の SDK はアプリセット ID（app set ID）、アプリや広告の操作、診断データ（起動時間、フリーズ、電力消費）を収集します。Google は IP アドレスを使って、市区町村程度のおおよその位置を推定することがあります。Google はこれらのデータを、同社のポリシーに従い、広告の配信と効果測定、統計、不正防止のために使用します。

欧州経済領域（EEA）、英国、スイス、および法律で求められるその他の地域では、パーソナライズド広告を配信する前に Google の同意フォーム（UMP）を表示します。選択はいつでも、設定 → 広告のプライバシー設定で変更できます。

広告の同意メッセージは、Google がすべての広告パートナー共通の文面で表示するため、正確な位置情報について触れています。Google によると、同社の広告 SDK が使うのは IP アドレスから推定されるおおよその位置情報のみで、このアプリが位置情報を渡すことは一切ありません。この利用は「オプションを管理」で拒否できます。

タグの中身が広告に渡ることはありません。広告のリクエストには、タグ、テンプレート、履歴のデータは一切含まれません。同意を拒否した場合はパーソナライズされていない広告が表示され、アプリはまったく同じように使えます。使えなくなる機能はありません。

タグからご自身で開くもの

タグの中身（リンク、電話、メール、SMS、地図、Wi-Fi ネットワーク、連絡先、アプリ）をボタンで開くと、Android がそれを対応するアプリ（ブラウザ、電話アプリ、メールアプリ、地図アプリ、Wi-Fi の設定、連絡先アプリ）に渡し、それ以降はそのアプリのプライバシーポリシーが適用されます。Arrímalo がそれをサーバーに送信することはありません。タグのタスクも同じです。アプリを閉じているときは、何を実行するかを先に表示し、「実行」をタップするまで待ちます。

IP アドレス

インターネットに接続するほかのアプリと同様に、広告をリクエストする際に Google のサーバーが IP アドレスを受け取ります。このアプリがほかのサーバーに接続することはありません。

法的根拠と保存期間

法的根拠。スマートフォン内で処理されるものは JR Soft には届きません。履歴、テンプレート、パスワードは、ご自身が求めることをアプリが行えるように保存されます（GDPR 第6.1.b条）。スマートフォンの外に送信されるものについては、次のとおりです。(1) 欧州経済領域、英国、スイスにおけるパーソナライズド広告と、広告目的での端末のストレージの使用：ご自身の同意。Google のフォームで同意するか拒否するかを選ぶことができ、設定 → 広告のプライバシー設定で撤回できます（GDPR 第6.1.a条および LSSI-CE 第22.2条）。(2) パーソナライズされていない広告、その効果測定、技術的な記録、不正防止：無料アプリの運営資金をまかない、正しく動作させ、不正から守るという正当な利益（GDPR 第6.1.f条）。(3) お問い合わせいただいた場合：返信し、お知らせいただいた用件を解決するという正当な利益（GDPR 第6.1.f条）。Google は、AdMob のデータを独立したデータ管理者として、同社のポリシーに従って取り扱います。「おやすみモード」へのアクセスは、Android の設定でご自身が許可し、いつでも取り消せます。この権限でアプリが行うのは、スマートフォン上でこのモードを切り替えることだけで、何も送信しません。

スマートフォンに保存されたデータは、ご自身で削除するか、アプリをアンインストールするか、アプリのデータを消去するまで保持されます。お送りいただいたメッセージ（用件が解決した時点で、遅くとも受信から 1 年後までに削除します）を除き、このアプリがスマートフォンの外にデータを保持することはありません。Google は、自社が収集したデータを同社のポリシーに従って保持します。

セキュリティ

アプリが保存するデータは、Android がほかのアプリのアクセスを許さないアプリ専用の領域に保存され、クラウドのバックアップにはアップロードされません。このアプリには、データ漏えいが起こりうる独自のサーバーやアカウントはありません。タグのパスワードは、スマートフォンの外に出ない Android の鍵保管庫（Android Keystore）の鍵で暗号化して保存され、どのバックアップにも含まれません。Google の広告 SDK の通信は暗号化されています（HTTPS）。お送りいただいたメッセージは JR Soft だけがアクセスできるメールアカウントに保管され、上記の期間内に削除されます。

タグのパスワードは簡単な鍵にすぎません。変更は防げますが、読み取りは防げません。また、アプリはほかで使っているパスワードを使わないよう注意を促します。アプリを閉じているときは、「実行」をタップしない限りタグのタスクが実行されることはありません。タスクのリンクに使えるのは、ウェブページ、地図、メール、SMS、電話アプリだけです。

ユーザーの権利

欧州連合（EU）にお住まいの場合、EU 一般データ保護規則（GDPR）により、アクセス、訂正、消去、処理の制限、データポータビリティ、異議申立ての権利が認められています。実際には、このアプリはご自身に結びつくデータをスマートフォンの外に一切保持しないため、次のように行使できます。

  • アクセス：アプリが保存しているものは、すべてアプリ内の「マイタグ」（履歴とテンプレート）で確認できます。
  • 訂正と消去：履歴の項目やテンプレートを個別に削除する、履歴を消去する、タグのパスワードを解除する（保存されたパスワードも削除されます）、またはアプリをアンインストールすることができます。広告 ID は、Android の設定 → Google → 広告でリセットまたは削除できます。
  • 異議申立てと同意の撤回：設定 → 広告のプライバシー設定。「おやすみモード」へのアクセスは、Android の設定から取り消せます。

Google のライブラリが収集するデータは Google が管理しており、それに関する権利は Google に対して行使します：policies.google.com/privacy。また、Agencia Española de Protección de Datos（スペインデータ保護庁）またはお住まいの国のデータ保護機関に苦情を申し立てることもできます（GDPR 第77条）。

米国にお住まいの方

独自のプライバシー法がある米国の州（カリフォルニア州、コロラド州、コネチカット州、テキサス州、バージニア州など）にお住まいの場合は、個人データを販売しないこと、またターゲティング広告のために共有しないことを求める権利があります。アプリの設定 → 広告のプライバシー設定 → 「Don’t sell or share my data」から手続きできます。それ以降は、パーソナライズされていない広告のみが表示されます。タグの中身、テンプレート、履歴はスマートフォンの中にとどまり、誰にも送信されません。広告のために、Google の SDK はデバイスの識別子とおおよその位置情報（市区町村レベル）を使用します。データに関するその他のご依頼は、demual@gmail.com までご連絡ください。
